# Dice Roller (RNG Injector)

Расширение для SillyTavern. Перед каждой генерацией ответа ИИ бросает кубик
(по умолчанию d20) и вписывает результат в чат — прямо перед последним
сообщением пользователя, так что ИИ видит бросок в контексте.

ИИ для самого броска не используется вообще: число считается чистым JS
(на основе текущего высокоточного времени, без Math.random()) в момент,
когда SillyTavern уже собирается отправить запрос модели. Токены на бросок
не тратятся — тратятся только на то, что модель прочитает уже готовую строку
вида «🎲 Бросок d20: 14 → итог 14».

## Установка

1. Скопируйте папку `dice-roller-rng` целиком в:
   `<папка SillyTavern>/public/scripts/extensions/third-party/dice-roller-rng`
   (либо через меню Extensions → Install Extension → указать путь к
   локальной папке / git-репозиторию, если вы положите это в свой репозиторий).
2. Перезапустите SillyTavern (или обновите страницу, если она уже запущена
   в браузере — новые расширения иногда подхватываются без рестарта сервера).
3. Откройте вкладку Extensions в SillyTavern — расширение появится в списке
   и добавит свою панель настроек с названием "🎲 Dice Roller (RNG Injector)".

## Настройки

- **Кубик** — сколько сторон (20 для d20, 6 для d6 и т.д.)
- **Модификатор** — прибавляется к результату броска
- **Не бросать для типов генерации** — список через запятую. По умолчанию
  `quiet` — это фоновые генерации (например саммари, инструкции без вывода
  в чат), для которых бросок не нужен. Если не хотите переброс при свайпе
  (регенерации ответа), добавьте туда `swipe` и `regenerate`.
- **Шаблон сообщения** — как выглядит вставляемая строка. Плейсхолдеры:
  `{{die}}`, `{{raw}}`, `{{modifier}}`, `{{modifier_str}}`, `{{total}}`, `{{label}}`
  (label — автоматическая пометка при результате 1 или максимум кубика).

## Как это стыкуется с вашим GM-пресетом

Расширение только поставляет число и текстовую метку критического успеха/
провала. Как именно ИИ трактует диапазоны (что считать провалом, что —
преимуществом) — решает уже ваш пресет `<narrative_impartiality_law>` и
соседние блоки. Если хотите зашить диапазоны прямо в бросок (например,
1-5 = провал, 6-14 = нейтрально, 15-19 = успех, 20 = крит), это делается
в `buildRollText()` в index.js — могу дописать при следующем заходе, если
понадобится.

## Технически: почему через generate_interceptor

Это официальный, документированный SillyTavern механизм: функция,
указанная в `generate_interceptor` манифеста, вызывается синхронно
непосредственно перед сборкой промпта для любого небей-run запроса
генерации. Она получает мутируемый массив `chat` — то, что мы туда
допишем, попадёт и в промпт для ИИ, и в видимую историю чата (значит,
бросок останется в логе разговора, как в настоящей партии).
